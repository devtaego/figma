## 01. 서비스 구조와 수익

### 서비스 구조 (IA)

- **상단**: 통합 검색창(+ 플레이스 에이전트), MY(방문 이력 · 예약 · 리뷰)
- **하단 탭 5개** (2025.11 개편): 발견 · 예약 · 대중교통 · 내비게이션 · 저장
- **허브**: 모든 경로가 **장소 상세(플레이스)** 로 모이고, 여기서 예약·주문·길찾기·저장·전화로 전환된다

### 사용자 흐름

1. **찾기** — 검색하거나 AI에게 물어본다
2. **고르기** — 리뷰·사진을 보고 고른다
3. **가기** — 예약하고 대중교통·내비로 출발한다
4. **남기기** — 방문 후 리뷰를 남기면 다음 사람이 참고한다 (순환)

### 수익 구조 — "쓰는 사람은 무료, 돈은 가게가 낸다"

| 수익원 | 누가 내나 | 과금 방식 |
| --- | --- | --- |
| 플레이스 광고 | 스마트플레이스 등록 업주 | CPC(최저 50원), 예약·전화·저장·길찾기 클릭도 과금 |
| AI 브리핑 광고 | 검색 광고주 | AI가 문안·노출 결정, 2026.7.21 노출 시작 |
| 네이버 예약 · 주문 | 업주 | 연동 수수료 (업종별 상이, 추정) |
| 네이버페이 | 업주 · 이용자 | 결제 수수료 |
| 지역소상공인 광고 | 지역 소상공인 | 지역 타깃 노출형 |
| Maps API | 기업 고객 | 네이버 클라우드 사용량 과금 |

지도 단독 매출은 비공개. 2026년부터 네이버 매출은 광고 / 서비스(플레이스·예약 포함)로 재분류.

## 02. 회사의 목표 · 전략 · 특성

- **지표**: MAU 3,000만+ (2025.11), 이용자 중 MZ세대 62%, 네이버 검색 점유율 64.39% (2026.4), 플레이스 에이전트 출시 (2026.9.17)
- **전략 1 · 온서비스 AI**: AI 브리핑(2025.3) → AI 탭 → 플레이스 에이전트. 2027년 통합 에이전트 목표
- **전략 2 · 로컬 올인원**: 예약 탭 신설과 BI 리브랜딩, 항공권·클래스까지 지도에서 예약
- **전략 3 · 데이터 해자**: 블로그·카페·방문자 리뷰와 스마트플레이스 업체 정보
- **특성**: 지도는 네이버 검색·커머스 광고의 '오프라인 출구'

## 03. 장단점

| 장점 | 단점 |
| --- | --- |
| 국내 최대 POI·리뷰 데이터 | 광고와 자연 노출 구분이 흐릿함 |
| 발견→예약→결제→리뷰를 한 앱에서 완결 | 조작 리뷰가 반복 적발됨 |
| 대중교통: 실시간, 승하차 알림 | 기능이 늘며 앱이 무거워짐 |
| 한·영·중·일 지도, 영문 내비 | 외국인: 한국어 위주 리뷰, 번역 품질 |
| 거리뷰 3D, AR 실내 내비, 계단 회피 | 핵심 기능이 로그인 전제 |

## 04. 문제점

- **P1 리뷰 조작의 산업화** — 5년간 허위 후기 2만 8,886건 적발, 의뢰 업체 707곳 중 병원 34.5%
- **P2 광고와 추천의 경계** — 에이전트 답변에 광고가 섞이면 추천 전체의 신뢰 하락
- **P3 외국인 경험과 구글 재진입** — 네이버 지도 불만 중 '다국어 미지원' 36.4%, 2026.2.27 구글 지도 반출 조건부 허가
- **P4 슈퍼앱화 복잡도** — 길찾기까지의 탭 수와 인지 부하 증가 (정성 분석)

## 07. 화면설계서

### A. 홈 (발견 탭)
1. 통합 검색창 — 장소·버스·지하철·주소 통합 검색
2. AI 에이전트 버튼 — 만 14세 이상 로그인 사용자
3. MY — 2025.11 개편으로 상단 이동
4. 카테고리 칩 — 음식점·카페·주차장 원탭 검색
5. 지도 · 장소 핀 — 광고 핀은 '광고' 라벨 필수
6. 내 주변 추천 시트 — 위치 동의 여부에 따라 기준 변경
7. 하단 탭 — 발견·예약·대중교통·내비·저장

### B. 장소 상세
1. 사진 갤러리
2. 장소 요약 — 별점(2026.4 재도입), 리뷰 수
3. 액션 버튼 — 예약·주문·전화·길찾기·저장 (광고 유입 시 과금 이벤트)
4. 기본 정보 — 영업시간, 주소, 메뉴
5. AI 리뷰 요약 — 'AI 생성' 표시
6. 방문자 리뷰 — 인증 배지, 조작 의심 리뷰 미노출
7. 하단 고정 CTA — 예약하기 / 길찾기

### C. 플레이스 에이전트
1. 헤더 · AI 고지
2. 사용자 질문 — 여러 조건을 한 문장으로
3. AI 답변 — 해석과 추천 이유
4. 장소 카드 — 저장·예약 바로 실행
5. 후속 질문 칩 — 멀티턴
6. 예약 신청 확인 — 최종 확인은 사용자가
7. 입력창
