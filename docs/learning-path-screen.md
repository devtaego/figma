# 학습 경로 화면 연습 (이미지 만들기 수업)

Figma: https://www.figma.com/design/1d3XvKcqXGvVO9Beixah0w

게이미피케이션 학습 경로 화면의 일반 구조(상단 스탯 바, 섹션 배너, 지그재그 스테이지, 보상 상자, 마스코트, 하단 탭 바)를 참고해 색상·아이콘·캐릭터를 새로 만든 오리지널 화면.

## 레이어 구성 포인트

- **입체 버튼 효과**: `Base / 입체 그림자`(어두운 색, 6px 아래) + `Top / 윗면` + `Highlight / 광택` 3겹
- **컴포넌트**: `Stage Node`(Done / Current / Locked), `Reward Box`(Ready / Locked) 베리언트. 화면의 노드는 모두 인스턴스
- **마스코트 '에그싹'**: 몸통·광택·눈·하이라이트·볼터치·입·새싹을 개별 도형으로 구성
- **오토 레이아웃**: 스탯 바와 탭 바
