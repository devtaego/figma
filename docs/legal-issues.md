# 네이버 지도 법적 이슈 처리 확인

**한 줄 요약: 내 위치, 내 정보, 나라 지도, 광고·리뷰, AI 답변. 이 다섯 가지를 지켜야 한다.**

| 법 | 쉽게 말하면 | 네이버 지도는 이렇게 처리 |
| --- | --- | --- |
| 위치정보법 | 내 위치는 내가 허락해야 쓸 수 있다 | 위치 권한 동의, 위치 이용 기록 자동 보관, 동의 철회 시 데이터 파기 |
| 개인정보보호법 | 무엇을 왜 얼마나 모으는지 미리 알려야 한다 | 개인정보처리방침 공개, 저장 목록 기본값은 '비공개'가 원칙 |
| 공간정보관리법 | 정밀 지도 해외 반출은 나라 허가가 필요하다 | 네이버는 해당 없음. 구글 반출 허가로 경쟁 환경 변화 |
| 표시광고법 | 광고는 광고라고 밝히고, 가짜 후기는 안 된다 | '광고' 배지, 조작 리뷰 AI 탐지 후 미노출 |
| AI 기본법 | AI가 만든 답이면 AI라고 알려야 한다 | 플레이스 에이전트에 AI 안내 문구 상시 표시 |

## 근거

- **위치 기록 보관**: 위치정보의 이용·제공 사실을 자동 기록하고 6개월 이상 보관하는 것이 법정 의무 (예: Google 위치정보 약관). 네이버 약관의 정확한 기간은 앱 설정에서 확인 필요
- **리뷰 조작 대응**: 직접 찍지 않은 영수증으로 리뷰를 올리는 행위를 '거짓 인증·리뷰 조작'으로 규정, AI 모듈로 탐지 시 계정 경고 또는 리뷰 미노출
- **AI 고지**: 플레이스 에이전트는 만 14세 이상 로그인 사용자에게 제공, 답변에 AI 안내 문구 상시 표기
- **지도 반출**: 2026.2.27 정부가 보안 조건을 전제로 구글의 1:5000 지도 반출 허가. 범위는 기본 바탕지도와 교통 네트워크, 한국 지도 전담관 국내 상주

## 참고 사례 — 카카오맵

새 즐겨찾기 폴더의 공개 여부 기본값이 '공개'여서 집·회사 등 저장 장소가 타인에게 노출됨. 개인정보위는 2022.2.23 공개 설정을 이용자 입장에서 정의하고 설계 단계부터 보호를 고려(Privacy by Design)하라고 권고.

→ 네이버 지도 저장 리스트 공유 기능도 기본값 '비공개' 필수.

## 개인정보처리방침 점검 체크리스트

- [ ] 수집 항목: 위치 · 검색 기록 · 저장 장소 · 예약/결제 정보
- [ ] 이용 목적과 항목별 보유기간이 짝지어 적혀 있는가
- [ ] 제3자 제공: 예약 시 업주에게 이름·연락처가 넘어가는가
- [ ] 처리 위탁 업체 목록과 국외 이전 여부
- [ ] 위치정보 동의 철회와 기록 삭제 방법
- [ ] 만 14세 미만 이용자 처리 기준
- [ ] 맞춤형 광고(행태정보) 거부 방법
- [ ] AI 에이전트 대화 내용의 보관·학습 활용 고지

> 일부 처리 방식은 공개 기사와 일반 원칙을 바탕으로 정리함. 발표 전 앱의 약관·개인정보처리방침 원문과 대조 권장.
